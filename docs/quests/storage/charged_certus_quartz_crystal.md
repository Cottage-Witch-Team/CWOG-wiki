
# Charged Certus Quartz Crystal



---
To obtain &bConsecrated Certus Quartz&r, you need only &atake Certus and consecrate it&r! It's that easy!

...Oh, you want to know &ohow&r. Fine. To &aConsecrate&r an item, pass it over a candle's flame, and the power of the elements will sanctify it. To put it simply: &6right click the &bQuartz&6 onto a &bCandle&r. You can use both &lvanilla&r Candles, and those from &lHexerei&r.

Vanilla candles will &aextinguish with use&r, but Hexerei ones will not. Additionally, if you were to set a &bDeployer&r to do it for you, it handles the crystals so delicately that the flame does not go out.
