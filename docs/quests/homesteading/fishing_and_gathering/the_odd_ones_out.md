
# The Odd Ones Out

The **Shrooma** can both be caught in *Mushroom Islands*.

The **Starshell Turtle** can be found anywhere in the *Twilight Forest*.

The **Box Turtle** and **Leech** are found exclusively in *Swamp biomes*. 

---



!!! tip
	### Acquire :
	- **Red Shrooma**
	- **Brown Shrooma**
	- **Box Turtle**
	- **Starshell Turtle**
	- **Leech**
