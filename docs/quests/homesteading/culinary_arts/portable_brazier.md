
# Portable Brazier

In order to &athaw an **Aspic**, you can either &6place it in a **Stew Pot** and let it convert, or you can use a **Portable Brazier**.

The **Brazier** can be done while traveling, but it will require a **Bowl of Water** and some **Vivid Charcoal** in order to work.
