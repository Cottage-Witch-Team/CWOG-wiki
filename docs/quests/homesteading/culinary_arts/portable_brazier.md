
# Portable Brazier

In order to &athaw an **Aspic**{.aqua}, you can either &6place it in a **Stew Pot**{.aqua} and let it convert, or you can use a **Portable Brazier**{.aqua}.

The **Brazier**{.aqua} can be done while traveling, but it will require a **Bowl of Water**{.aqua} and some **Vivid Charcoal**{.aqua} in order to work.
