
# Gravy Boat

A **Gravy Boat** is crucial to making *Stir Fried dishes*. It's crafted by *resting*, which is a unique mechanic involving ==putting things in a **Dolium** and then &6leaving it the heck alone==.
{image:cottagewitch:textures/gravyboat.png width:100 height:100 align:1 fit:true}
In this image, you can see there are *at least 8 **Walnuts**, one **Anvil**, and one **Glass Bottle** (you can also use an empty Gravy Boat) in the **Dolium**. All of these must be present in order for the &aresting process* to begin. Be aware that this ^^takes a very long time^^. Most resting takes ^^an in-game day^^ to complete.

You can speed it up by using **Time in a Bottle**.
