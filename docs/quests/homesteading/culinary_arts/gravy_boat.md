
# Gravy Boat

A **Gravy Boat**{.aqua} is crucial to making **Stir Fried dishes**{.green}. It's crafted by **resting**{.green}, which is a unique mechanic involving **putting things in a **Dolium**{.aqua} and then &6leaving it the heck alone**{.gold}.
{image:cottagewitch:textures/gravyboat.png width:100 height:100 align:1 fit:true}
In this image, you can see there are **at least 8 **Walnuts**{.aqua}, one **Anvil**{.aqua}, and one **Glass Bottle**{.aqua} (you can also use an empty Gravy Boat) in the **Dolium**{.aqua}. All of these must be present in order for the &aresting process**{.green} to begin. Be aware that this **takes a very long time**{.pink}. Most resting takes **an in-game day**{.pink} to complete.

You can speed it up by using **Time in a Bottle**{.aqua}.
