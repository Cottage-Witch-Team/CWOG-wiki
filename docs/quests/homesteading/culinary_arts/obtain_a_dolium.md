
# Obtain a Dolium

> The doldrums

---

# Task:

- Acquire Any Dolium
---

The **Dolium** is used for *Resting Conversion*, which consists of placing your *ingredients and other items* inside and ==letting them rest==, for up to an *in-game day*.
Each recipe needs all ingredients, as well as a container to hold the result, and sometimes an additional item (such as *Anvils for Gravy Boats*). ^^The resting process will not begin without all components^^.
This can be sped up using the **Time in a Bottle**.
