
# Construction Paste Container T1

> Don't eat the paste

---



!!! tip "Task:"

	- Acquire Construction Paste Container T1
---


**Construction Paste** allows you to build with blocks you technically don't have.

When you are pasting in a structure, if you are missing blocks from the build, but have **Paste**, it will *take on the appearance of that block*. When broken, it will drop **Construction Paste**, however.

The **Paste Containers** allow you to hold significantly more paste than you would be able to, otherwise.
