
# Construction Paste Container T1

> Don't eat the paste

---


**Construction Paste**{.aqua} allows you to build with blocks you technically don't have.

When you are pasting in a structure, if you are missing blocks from the build, but have **Paste**{.aqua}, it will **take on the appearance of that block**{.green}. When broken, it will drop **Construction Paste**{.aqua}, however.

The **Paste Containers**{.aqua} allow you to hold significantly more paste than you would be able to, otherwise.
