
# Furniture Station

> Ideas above your station

---


The mod **Fantasy's Furniture**{.glow} adds beautiful and intricate furniture for you to decorate with.

The crafting system is a little different from usual, however. Each recipe costs only 1 each of **Clay, Cobbled Stone, and Planks**{.aqua}, and must be created in a **Furniture Station&b, which can be &acrafted in a Smithing Table&a using a &bCrafting Table**{.aqua} and **Leather**{.aqua}.

---



!!! tip "TASK" 

	- Acquire **Furniture Station**
