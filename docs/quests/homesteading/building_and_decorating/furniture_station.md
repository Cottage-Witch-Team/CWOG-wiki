
# Furniture Station

> Ideas above your station

---

# Task:

- Acquire Furniture Station
---

The mod ***Fantasy's Furniture*** adds beautiful and intricate furniture for you to decorate with.

The crafting system is a little different from usual, however. Each recipe costs only 1 each of **Clay, Cobbled Stone, and Planks**, and must be created in a **Furniture Station&b, which can be &acrafted in a Smithing Table&a using a &bCrafting Table** and **Leather**.
