
# Compacting Drawer

The **Compacting Drawer**{.aqua} is unique from other drawers because it allows you to access **multiple compressions of an item**{.green}.

 The usual example would be something like **Iron**{.aqua}, because it will give you access to **Iron Blocks**{.aqua}, **Iron Ingots**{.aqua}, and **Iron Nuggets**{.aqua}. If you insert 9 Iron Ingots, you can withdraw either 1 Block, 9 Ingots, or 81 Nuggets, without having to craft.

However, this also works for items such as **Crops**{.aqua}, which can be withdrawn as Crates. This works with any item which has a **3x3 compression recipe**{.green}.

The **Simple Compacting Drawer**{.aqua} does the same thing, except for items which only have 2 variations, such as crops or eggs.
