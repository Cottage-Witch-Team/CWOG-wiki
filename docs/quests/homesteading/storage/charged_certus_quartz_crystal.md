
# Charged Certus Quartz Crystal

To obtain **Consecrated Certus Quartz**, you need only *take Certus and consecrate it*! It's that easy!

...Oh, you want to know &ohow&r. Fine. To *Consecrate* an item, pass it over a candle's flame, and the power of the elements will sanctify it. To put it simply: &6right click the **Quartz&6 onto a &bCandle**. You can use both ***vanilla*** Candles, and those from ***Hexerei***.

Vanilla candles will *extinguish with use*, but Hexerei ones will not. Additionally, if you were to set a **Deployer** to do it for you, it handles the crystals so delicately that the flame does not go out.
