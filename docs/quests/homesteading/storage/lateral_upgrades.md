
# Lateral Upgrades


!!! tip "Task:"
	## Acquire :
	- Collector Upgrade
	- Puller Upgrade
	- Pusher Upgrade

---


The **Collector Upgrade** will *pick up items* dropped nearby.
The **Pulling Upgrade** will *pull items from a nearby inventory*.
The **Pushing Upgrade** will... you guessed it! *Push items* to a nearby inventory.
