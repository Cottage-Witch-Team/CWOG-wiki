
# Lateral Upgrades

The **Collector Upgrade**{.aqua} will **pick up items**{.green} dropped nearby.
The **Pulling Upgrade**{.aqua} will **pull items from a nearby inventory**{.green}.
The **Pushing Upgrade**{.aqua} will... you guessed it! **Push items**{.green} to a nearby inventory.
