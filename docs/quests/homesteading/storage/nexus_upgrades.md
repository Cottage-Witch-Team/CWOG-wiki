
# Nexus Upgrades

Some blocks can be *upgraded* to have *additional features*! To find out what blocks can be used for each upgrade, ==simply hover over the tablet== to see the *list of accepted blocks*. The number in parentheses is the *maximum amount of that upgrade the block can accept*. 


^^Note: some blocks are disabled, but still listed on the tablet^^. These blocks will say (Disabled). For a full list of blocks/items from ***AE2***, their *name changes,* and *whether or not they are disabled*, please ==click the Transcendent Gem next to this quest== to visit the spreadsheet with these details.
