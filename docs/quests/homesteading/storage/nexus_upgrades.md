
# Nexus Upgrades

Some blocks can be **upgraded**{.green} to have **additional features**{.green}! To find out what blocks can be used for each upgrade, **simply hover over the tablet**{.gold} to see the **list of accepted blocks**{.green}. The number in parentheses is the **maximum amount of that upgrade the block can accept**{.green}. 


**Note: some blocks are disabled, but still listed on the tablet**{.pink}. These blocks will say (Disabled). For a full list of blocks/items from **AE2**{.glow}, their **name changes,**{.green} and **whether or not they are disabled**{.green}, please **click the Transcendent Gem next to this quest**{.gold} to visit the spreadsheet with these details.
