
# Basic Upgrade

The **Basic Pipe Upgrade**{.aqua} allows you to set a **Redstone Mode**{.green} for the Pipe. You can set it to **only be active**{.green} when receiving a signal, or to **stop when it receives a signal**{.green}. By default, it will **ignore Redstone input**{.green}.
