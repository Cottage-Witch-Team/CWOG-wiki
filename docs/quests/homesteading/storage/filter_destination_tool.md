
# Filter Destination Tool

The **Filter Destination Tool** is a multi-use tool which will allow you to *set the destination* of a **filtered item type**.
You can assign it an inventory by &6right clicking it ***on the face of the block the &bPipe&6 connects to***. It will not work if you do not select the correct face of the inventory.

	- Acquire **Filter Destination Tool**
