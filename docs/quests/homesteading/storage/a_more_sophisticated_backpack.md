# Task:

- Acquire Backpack
---

This backpack is no kid's toy- this thing is multipurpose and heavy duty! With access to a *plethora of unique upgrades to equip* and the ability to improve the backpack's storage by ==crafting it with increasingly expensive ingots==, this is truly an endgame storage solution for on-the-go witches.

You can place this backpack down/pick it up by ==shift right clicking== it. You can *open it with &6b* and &aequip it in your **Back curio slot** to free up inventory space. This keybind ^^may overlap^^ with the backpacked keybind.

Backpacks can be found only in *End City* loot, making them an extremely valuable late game find. 

Caution: although you can block other players from opening your backpack while you wear it, there is ^^no way to protect against this backpack being stolen^^ if you set it down or put it in a chest.
