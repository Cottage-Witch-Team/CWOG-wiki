
# Configuration Tool

**Configuration Tools**{.green} alter the function of Drawers. **Right click on a Drawer while holding a Key**{.gold} to activate its ability.

The basic mode, **Locking**{.aqua}, locks a Drawer so that it can only accept the item/s currently inside of it.
The **Hide/Show Amounts**{.aqua} mode toggles whether or not the amount of items contained within the Drawer is visible on its surface.

The **Hide/Show Item Renders**{.aqua} mode will completely hide the item image and all other labels from the front of the Drawer.

The **Hide/Show Upgrades**{.aqua} will show or hide what upgrades a Drawer currently contains.
