
# The Sculk Network Basics

The first tools you'll need are an **Emitter** - to send out items - and a **Receiver** - to, well, receive them.

The **Emitter** must be &6placed on top of the **Sculk Barrel** in order to function. The **Sculk Receiver**, however, can input into *most basic inventory blocks* such as Chests, Barrels, and Drawers. It *cannot deposit directly* into a **Drawer Controller**, but you can use **Pipez** or **Pulling Upgrades** to withdraw the items into your Drawers.
