
# The Sculk Network Basics

The first tools you'll need are an **Emitter**{.aqua} - to send out items - and a **Receiver**{.aqua} - to, well, receive them.

The **Emitter**{.aqua} must be &6placed on top of the **Sculk Barrel**{.aqua} in order to function. The **Sculk Receiver**{.aqua}, however, can input into **most basic inventory blocks**{.green} such as Chests, Barrels, and Drawers. It **cannot deposit directly**{.green} into a **Drawer Controller**{.aqua}, but you can use **Pipez**{.aqua} or **Pulling Upgrades**{.aqua} to withdraw the items into your Drawers.
