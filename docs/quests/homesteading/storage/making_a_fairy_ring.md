
# Making a Fairy Ring

> A bit of help from the fae

---

# Tasks:

- Acquire Any Mushrooms (8)
- Build the Fairy Circle
---

Collecting 8 mushrooms and *placing them in a ring* will create a fairy ring. Make sure to place them on *blocks that can grow mushrooms*, such as **mycelium**. You can then ==drop items into the fairy ring== to *create new items*!
