
# Summon The Wilden Chimera

> To Become An Archmage, You Must Fight

---
In order to make certain items, you'll need to defeat the boss, &eThe Wilden Chimera&r. This does not spawn naturally, and must be summoned via &aRitual&r.

It's suggested to be using tier 2 armor and spells before engaging this boss.

To summon him, you'll need to find a &eWilden Hunter&r, &eWilden Guardian&r, and &eWilden Stalker&r, and obtain their &btrophies&r.
