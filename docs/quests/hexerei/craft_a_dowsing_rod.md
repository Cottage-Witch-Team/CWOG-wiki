
# Craft A Dowsing Rod

> A Magical Compass To Lead The Way

---
In order to locate much of the content of this mod, one must first locate a &aSwamp&r or &aJungle&r biome. These can be found either with the &bNature's Compass&r, or the &bDowsing Rod&r.

The &bDowsing rod&r's leaves will &achange colors when it points towards&r one of the aforementioned biomes. If one crafts it into the &bNature's Compass&r, you can &asearch the surrounding area&r for any biome.
