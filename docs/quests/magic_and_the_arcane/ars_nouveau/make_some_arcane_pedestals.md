
# Make Some Arcane Pedestals

> I Love A Good Pedal-stool

---
Craft an &bArcane Pedestal&r in a Crafting Bench using &bSourcestone&r.

These Pedestals need to be placed surrounding the &bImbuement Chamber&r or &bEnchanting Apparatus&r. You can do either a + pattern or an x pattern. Both are valid.

&6Use JEI to find the recipe&r for each Glyph. Only the Source Gem is consumed, so don't worry about using expensive reagents.
