
# Summon the Wilden Chimera

> To become an archmage, you must fight

---


In order to make certain items, you'll need to defeat the boss, **The Wilden Chimera**{.yellow}. This does not spawn naturally, and must be summoned via **Ritual**{.green}.

It's suggested to be using tier 2 armor and spells before engaging this boss.

To summon him, you'll need to find a **Wilden Hunter**{.yellow}, **Wilden Guardian**{.yellow}, and **Wilden Stalker**{.yellow}, and obtain their **trophies**{.aqua}.

---



!!! tip "TASK" 
	### Acquire :
	- **Ritual Wilden Summon**
	- **Wilden Tribute**
