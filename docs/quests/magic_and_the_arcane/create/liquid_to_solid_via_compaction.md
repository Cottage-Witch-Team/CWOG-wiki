
# Liquid to Solid via Compaction

Now that you have your **Melted Chocolate**, you'll want to &6compact it into Bars using a **Mechanical Press**.
Place a **Basin** beneath a **Mechanical Press** and either *pump or bucket* the Chocolate into the Basin.
With enough power, the **Press** will automatically turn the liquid into **Chocolate Bars**, which can be retrieved by ==right clicking with an empty hand==.
