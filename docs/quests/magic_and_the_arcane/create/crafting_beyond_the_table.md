
# Crafting Beyond The Table

Interested in **auto-crafting, but don't have any &eWixies**{.green} yet? Try **Mechanical Crafters**{.aqua}.

Set them up in the correct shape and provide them with **Rotational Force**{.green} to get them going. You can feed items into them using many options - **Mechanical Arms, Hoppers, Pipez**{.aqua}, or others!

You need to be sure to &6align their arrows correctly using the **Wrench**{.aqua}, so that they all **output to a single slot**{.green}. This is required for them to work.
{image:cottagewitch:textures/mechanicalcrafter.png width:100 height:100 align:1 fit:true}
This image is only **one example**{.green} of a shape you can place them in. You can do a simple 3x3 for most recipes, but **you'll need the above setup for the next quest**{.pink}.
