
# Andesite Casing

**Andesite Casing** is one of three different tiers of Casing, used to craft various machinery. It is crafted by applying **Andesite Alloy** to a **Stripped Log**. You can do this &6manually by placing the **Stripped Log** in world and &6right clicking it with the **Andesite Alloy**. It can also be automated by using a **Deployer**.

!!! tip

	- Acquire **Andesite Casing**
