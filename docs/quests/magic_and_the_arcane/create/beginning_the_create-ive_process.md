
# Beginning the Create-ive Process


!!! tip "Task:"

	- I'm Ready!
---


***Create*** is an incredible mod focusing on low-tech automation and machinery. I am sure I don't need to explain to you that physics, science, and magic are all closely interrelated. Why not dabble a bit in *tech witchery*? Unlike many tech mods, the basic energy type Create uses is *rotational force*, which can be generated in a number of ways.
These quests will help to guide you through the basics, but ultimately the final products will be up to you and your imagination! Thankfully, there is a robust in-game documentation system called ^^Pondering^^, which can be accessed by ==holding the “w” key down when hovering over an item== in your inventory or in JEI. Make sure you aren’t typing in a text field first, though!
To begin with, take this **Wrench**. You can ==right click on most Create blocks== to rotate them or alter them in some way. ^^Which side of the block you click on^^ determines which way the object rotates. Additionally, you can ==shift right click== most Create items (and some vanilla, such as levers or hoppers) *to instantly remove them directly into your inventory*. An incredibly useful feature!
