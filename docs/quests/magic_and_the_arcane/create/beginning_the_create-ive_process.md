
# Beginning the Create-ive Process

**Create**{.blue} is an incredible mod focusing on low-tech automation and machinery. I am sure I don't need to explain to you that physics, science, and magic are all closely interrelated. Why not dabble a bit in **tech witchery**{.green}? Unlike many tech mods, the basic energy type Create uses is **rotational force**{.green}, which can be generated in a number of ways.
These quests will help to guide you through the basics, but ultimately the final products will be up to you and your imagination! Thankfully, there is a robust in-game documentation system called **Pondering**{.pink}, which can be accessed by &6holding the 
 key down when hovering over an item&r in your inventory or in JEI. Make sure you aren’t typing in a text field first, though!
To begin with, take this **Wrench**{.aqua}. You can **right click on most Create blocks**{.gold} to rotate them or alter them in some way. **Which side of the block you click on**{.pink} determines which way the object rotates. Additionally, you can **shift right click**{.gold} most Create items (and some vanilla, such as levers or hoppers) **to instantly remove them directly into your inventory**{.green}. An incredibly useful feature!
