
# Obtain a Warp Scroll

The **Warp Scroll** is a one-time use item which can *warp to any Waystone from anywhere in the world*. It does not have a cooldown, but the item is consumed upon use.
Simply ==hold right click with it in your hand== in order to activate it. If you take damage or let go while it is charging, ^^the warp will cancel^^.
These should not be confused with the **Warp Scrolls** from ^^Ars Nouveau^^, which have the same name but a different function.
