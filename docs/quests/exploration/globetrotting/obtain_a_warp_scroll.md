
# Obtain a Warp Scroll

The **Warp Scroll**{.aqua} is a one-time use item which can **warp to any Waystone from anywhere in the world**{.green}. It does not have a cooldown, but the item is consumed upon use.
Simply **hold right click with it in your hand**{.gold} in order to activate it. If you take damage or let go while it is charging, **the warp will cancel**{.pink}.
These should not be confused with the **Warp Scrolls**{.aqua} from **Ars Nouveau**{.pink}, which have the same name but a different function.
