
# Reanimated Ruins

There are *three types* of *Reanimated Ruins*. Which one you complete will determine which *new map you unlock*. You only need to find one to complete this quest, but if you wish to *obtain all the unique artifacts*, you'll need to ==seek out more ruins==!

---



!!! tip ""
	### Find :
	- **Reanimated Ruins Frozen**
	- **Reanimated Ruins Mesa**
	- **Reanimated Ruins Mossy**
