
# Reanimated Ruins

There are **three types**{.green} of **Reanimated Ruins**{.red}. Which one you complete will determine which **new map you unlock**{.green}. You only need to find one to complete this quest, but if you wish to **obtain all the unique artifacts**{.green}, you'll need to **seek out more ruins**{.gold}!

---



!!! tip "TASK" 
	### Find :
	- **Reanimated Ruins Frozen**
	- **Reanimated Ruins Mesa**
	- **Reanimated Ruins Mossy**
