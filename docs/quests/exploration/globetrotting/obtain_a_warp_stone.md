
# Obtain a Warp Stone

The **Warp Stone**{.aqua} is an item which will allow you to **warp to any Waystone from anywhere in the world**{.green}. It is a multi-use item, which has a cooldown between uses.
Simply **hold right click with it in your hand**{.gold} in order to activate it. If you take damage or let go while it is charging, **the warp will cancel**{.pink}.
