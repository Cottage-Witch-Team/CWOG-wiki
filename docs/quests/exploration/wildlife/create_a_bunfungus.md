
# Create a Bunfungus

Feed a **Rabbit** some **Mungal Spores** to create a **Bunfungus**, a rather large and disturbing neutral creature which will defend the nearby area. They can be healed with **Carrots**, and drop **Bunfungus** meat, which can be used in cooking.

---



!!! tip ""

	- Acquire **Mungal Spores**
