
# Gateways to Eternity

Looking for a challenge? Why not craft yourself a **Gate Pearl**? ^^You can craft any one you'd like for this quest^^.
A **Gate Pearl** allows you to summon a **Gateway** by using it on a block.There will need to be *sufficient space* available, and *another Gateway cannot already be open*.
An open Gateway will ^^fail in a burst of lightning^^ if it *cannot spawn a mob*, any active *mob gets too far away*, or the *wave timer* elapses. Rewards will spawn from the Gateway as they are obtained.
These **Gateway** provide a challenge for powerful players, and are a great source of **Mob Drops**.

Additionally, some mobs which have been ^^removed for phobia reasons^^ can be found only in Gatepearls. If you wish to encounter snakes or insects, the Gatepearl is the only way to find them!
