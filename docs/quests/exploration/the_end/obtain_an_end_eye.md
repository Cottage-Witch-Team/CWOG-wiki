
# Obtain an End Eye

> I've got my eye on the end

---


Normally, to get to **The End**{.pink} requires regular old **Ender Eyes**{.aqua}, for both seeking and filling the portal frames. However, magic has warped this world, making it more difficult to face the final dimension.
There are, instead, 16 other eyes (you'l,l need 12 unique eyes to open the portal), which can be found in various ways. **See the following quests**{.gold} for more information on them.

To seek the **Stronghold**{.pink}, you can use any of these eyes the way you would use a regular **Ender Eye**{.aqua}. Be careful though- **they still break!**{.green} Maybe only use any doubles you've found for this. Alternatively, you can locate the Stronghold with an **Explorer's Compass**{.aqua} and save your eyes!
