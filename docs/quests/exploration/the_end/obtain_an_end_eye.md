
# Obtain An End Eye

> I've Got My Eye On The End

---
Normally, to get to &dThe End&r requires regular old &bEnder Eyes&r, for both seeking and filling the portal frames. However, magic has warped this world, making it more difficult to face the final dimension.
There are, instead, 16 other eyes (you'l,l need 12 unique eyes to open the portal), which can be found in various ways. &6See the following quests&r for more information on them.

To seek the &dStronghold&r, you can use any of these eyes the way you would use a regular &bEnder Eye&r. Be careful though- &athey still break!&r Maybe only use any doubles you've found for this. Alternatively, you can locate the Stronghold with an &bExplorer's Compass&r and save your eyes!
