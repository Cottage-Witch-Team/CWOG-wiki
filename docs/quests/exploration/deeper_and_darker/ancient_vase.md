
# Ancient Vase

**Ancient Vases** are loot containers which can contain **Warden Carapaces** in rare instances. This may help you to *craft the Warden Helmet* before killing the **Warden**.

However, be wary, as *each time a Vase is broken*, there is a chance to spawn **The Stalker**, which is a relative of the **Warden**.
