
# Defeat the Warden

The **Warden**{.yellow} pulls no punches. It is easily capable of killing the unprepared witch in a single hit, and it is **incredibly sturdy**{.green}. However, with the right preparation one might be able to face it!

The **Warden**{.yellow} is blind, and will seek out players by **smell and hearing**{.green}. If it does not detect any players for one minute, it will **burrow back underground**{.green}.
