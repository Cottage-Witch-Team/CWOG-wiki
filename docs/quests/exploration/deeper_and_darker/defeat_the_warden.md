
# Defeat the Warden

The **Warden** pulls no punches. It is easily capable of killing the unprepared witch in a single hit, and it is *incredibly sturdy*. However, with the right preparation one might be able to face it!

The **Warden** is blind, and will seek out players by *smell and hearing*. If it does not detect any players for one minute, it will *burrow back underground*.
