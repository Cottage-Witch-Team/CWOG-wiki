
# Magic Map Focus

> Come on, focus!

---


Craft a **Magic Map Focus**{.aqua} with a **Raven Feather**{.aqua}, some **Glowstone Dust**{.aqua}, and **Torchberries**{.aqua} (which can be found in Twilight Forest caves).
Then you can surround it with **Paper**{.aqua} to create a Magic Map, which will prove invaluable to your quest through the **Twilight Forest**{.pink}.

---



!!! tip "TASK" 

	- Acquire **Magic Map Focus**
