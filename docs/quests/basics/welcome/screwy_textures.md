
# Screwy Textures?

Have you found that your ***Sophisticated Storage*** or ***Chipped*** textures seem messed up?

This is a known bug which is currently unfixed by the mod developers. It occurs most often when *resourcepacks are changed with the game running*. It can be fixed by ==restarting Minecraft==.
