
# Screwy Textures?

Have you found that your **Sophisticated Storage**{.glow} or **Chipped**{.glow} textures seem messed up?

This is a known bug which is currently unfixed by the mod developers. It occurs most often when **resourcepacks are changed with the game running**{.green}. It can be fixed by **restarting Minecraft**{.gold}.
