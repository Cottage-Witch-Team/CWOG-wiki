
# Capture Time in a Bottle

Did you know that you can *speed up the tick speed of a block*? This can be used on things like **Compost** to make them progress faster.

Craft the **Time in a Bottle** and hold it in your inventory to accumulate time. Then, you can ==shift right click== on certain blocks to apply that time to them.
