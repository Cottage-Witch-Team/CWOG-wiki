
# Item Magnet

Crafted with **Cinnabar**{.aqua} and **Magnetite**{.aqua}, this incredibly useful tool will **draw items on the ground to you**{.green} for pickup!

Simply **right click while holding it**{.gold} to activate it, and then **keep it in your inventory**{.green}. You can turn it off the same way.
