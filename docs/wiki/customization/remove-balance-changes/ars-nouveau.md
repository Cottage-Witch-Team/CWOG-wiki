## Drygmy drops

File: `Cottage Witch\kubejs\server_scripts\tags\entity_tags.js`  
Tag list: `"ars_nouveau:drygmy_blacklist"`

This list blocks specific entities from Drygmy drop generation.

Example: `artifacts:mimic` in the blacklist means Drygmies do not produce mimic loot.
