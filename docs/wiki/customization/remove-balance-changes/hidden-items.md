# Removed and Hidden Items

These are items with no crafting recipe and hidden in JEI.

## Unobtainable list location

For versions `1.17.6+`:

`Cottage Witch\kubejs\startup_scripts\globals\global_consts.js`

For versions `1.17.5 and below`:

`Cottage Witch\kubejs\server_scripts\recipes\recipe_removal.js`

## Re-enable behavior

- To restore recipes: remove items from the unobtainable list.
- To show items in JEI: remove items from `Cottage Witch\kubejs\client_scripts\jeihide.js`.
