# Slowness When Holding 2+ Backpacks

If you want to disable the slowness nerf:

1. Open the world/server config file:
`Cottage Witch\saves\<YOUR_WORLDNAME>\serverconfig\sophisticatedbackpacks-server.toml`

2. Find section:
`[server.nerfs]`

3. Change:
`tooManyBackpacksSlowness = true`
to
`tooManyBackpacksSlowness = false`

4. Restart game/server to apply.
