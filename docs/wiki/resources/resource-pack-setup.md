# Resource Pack Setup

Enable all included resource packs except these preference-only packs:

- Black Icons
- Twilight Classic
- Classic Icons
- Create Legacy Copper
- Katu's Carpets Alternate
- Quark Programmer Art
- Programmer Art
- Better Vanilla Gems
- Emissive Better Vanilla Gems
- Emissive Ores
- Unlit Redstone Ores
- Darker Ropes
- White Icons

## Order

Pack order should not matter in this modpack because these packs were adjusted to be compatible.
