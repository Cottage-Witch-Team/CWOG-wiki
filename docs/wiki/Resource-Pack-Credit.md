# What Resource Packs Should I Enable?
We recommend enabling everything except the following, which are user-preference only:
- Black Icons
- Twilight Classic
- Classic Icons
- Create Legacy Copper
- Katu's Carpets Alternate (you can add this if you want)
- Quark Programmer Art
- Programmer Art
- Better Vanilla Gems
- Emissive Better Vanilla Gems
- Emissive Ores
- Unlit Redstone Ores
- Darker Ropes
- White Icons

The order in which you enable the resourcepacks should not matter, as they are edited to be compatible with one another.
