# Find Biomes with the Nature's Compass

The **Nature's Compass**{.aqua} is a magical tool, similar to a **Dowsing Rod**{.aqua}, which will allow you to find your way to a particular type of biome.

Simply **right click while holding it**{.gold} in order to search for the biome you want to find.
