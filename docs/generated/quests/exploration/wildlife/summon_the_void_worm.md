# Summon the Void Worm

> A multi-phase boss fight

The **Void Worm**{.yellow} is a boss fight which can be summoned by throwing a **Mysterious Worm**{.aqua} into the void in **The End**{.pink}. He summons crystalline projectiles, has a devastating bite, and is capable of opening portals.

When defeated, it drops its **Eyes**{.aqua} and **Beak**{.aqua}. These can be crafted into a **Dimensional Carver**{.aqua} : a pickaxe which can mine a temporary portal through space and to the player's spawn point, and the **Void Worm Effigy**{.aqua} : a trophy that, when provided with redstone signal, chomps down on whatever is in front of it.
