# Create a Bunfungus

Feed a **Rabbit**{.yellow} some **Mungal Spores**{.aqua} to create a **Bunfungus**{.yellow}, a rather large and disturbing neutral creature which will defend the nearby area. They can be healed with **Carrots**{.aqua}, and drop **Bunfungus**{.aqua} meat, which can be used in cooking.
