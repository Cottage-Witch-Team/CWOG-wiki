# Gateways to Eternity

Looking for a challenge? Why not craft yourself a **Gate Pearl**{.aqua} ? **You can craft any one you'd like for this quest**{.pink}.

A **Gate Pearl**{.aqua} allows you to summon a **Gateway**{.yellow} by using it on a block.There will need to be **sufficient space**{.green} available, and **another Gateway cannot already be open**{.green}.

An open Gateway will **fail in a burst of lightning**{.pink} if it **cannot spawn a mob**{.green}, any active **mob gets too far away**{.green}, or the **wave timer**{.green} elapses. Rewards will spawn from the Gateway as they are obtained.

These **Gateway**{.yellow} provide a challenge for powerful players, and are a great source of **Mob Drops**{.aqua}.



Additionally, some mobs which have been **removed for phobia reasons**{.pink} can be found only in Gatepearls. If you wish to encounter snakes or insects, the Gatepearl is the only way to find them!
