# Meet the Flutter

The **Flutter**{.yellow} is a passive mob which loves flowers.

It can be tamed if given some, but **each flower must be a different type**{.pink} or it won't accept them.

It will defend its owner if told to follow - and can be given a **Flower Pot**{.aqua} to rest in. **Shift click the potted Flutter**{.gold} to pick it up for transport.
