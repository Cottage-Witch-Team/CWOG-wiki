# Rainbow Jelly

> Jellyfish in the sky~ i can go twice as high~

Defeat a **Rainbow Jelly**{.yellow} to obtain a drop which can craft **Rainbow Glass**{.aqua}. You can also **right click it onto an entity**{.gold} to paint that entity rainbow. Wipe them clean with a sponge, if you wish.
