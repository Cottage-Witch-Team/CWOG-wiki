# Ancient Vase

**Ancient Vases**{.aqua} are loot containers which can contain **Warden Carapaces**{.aqua} in rare instances. This may help you to **craft the Warden Helmet**{.green} before killing the **Warden**{.yellow}.



However, be wary, as **each time a Vase is broken**{.green}, there is a chance to spawn **The Stalker**{.yellow}, which is a relative of the **Warden**{.yellow}.
