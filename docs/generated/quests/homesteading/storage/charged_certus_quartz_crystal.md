# Charged Certus Quartz Crystal

To obtain **Consecrated Certus Quartz**{.aqua}, you need only **take Certus and consecrate it**{.green} ! It's that easy!...Oh, you want to know **how**{.italic}. Fine. To **Consecrate**{.green} an item, pass it over a candle's flame, and the power of the elements will sanctify it. To put it simply: **right click the**{.gold} **Quartz**{.aqua} **onto a**{.gold} **Candle**{.aqua}. You can use both **vanilla**{.blue} Candles, and those from **Hexerei**{.blue}.



Vanilla candles will **extinguish with use**{.green}, but Hexerei ones will not. Additionally, if you were to set a **Deployer**{.aqua} to do it for you, it handles the crystals so delicately that the flame does not go out.
