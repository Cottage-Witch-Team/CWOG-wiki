# Fuzzy Card

When adding an **NBT item to a filter**{.green}, by default, the filter will attempt to **match its NBT**{.green}. The **Fuzzy Tablet**{.aqua} allows you to filter items as if they did not have NBT. 



For example, when **adding a potion to an**{.green} **Import Fulcrum**{.aqua} 's filter, only the **specific type of potion will be imported**{.green}. By adding a **Fuzzy Tablet**{.aqua} on the "Match Any" mode to the **Import Fulcrum**{.aqua}, **any potion type will be imported**{.green}.



The **Fuzzy Tablet**{.aqua} allows for additional filtering by **damage levels**{.green}. This can be used for **filtering out damaged tools or armor**{.green} with finer detail. **Note: storing NBT items within your Nexus can cause lag**{.pink}
