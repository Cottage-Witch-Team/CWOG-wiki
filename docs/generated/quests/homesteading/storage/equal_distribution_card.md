# Equal Distribution Card

The **Equal Distribution Tablet**{.aqua} **splits a Glyphstone into equally sized sections**{.green}, based on the filter that you set for the **Glyphstone**{.aqua} using the **Glyph Workbench**{.aqua}. This prevents one item type from completely filling the Glyphstone.
