# Storage Tool

To **remotely link Sophisticated Storages**{.green} which are not touching the main network, you need to **place a**{.gold} **Storage Link**{.aqua} **on them**{.gold}, and then **right click the**{.gold} **Storage Tool**{.aqua} on the **Link**{.aqua} and the **Storage Controller**{.aqua}.
