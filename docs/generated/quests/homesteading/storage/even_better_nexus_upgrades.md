# Even Better Nexus Upgrades

In addition to the **Carved Certus Tablets**{.aqua}, you can also craft **advanced upgrades**{.green} using **Fluix Tablets**{.aqua}.



Fluix as a crystal has certain properties - a pseudo-sentience, if you will. In order to perform tasks which require some "smart" functions, it's a much better choice than plain **Certus**{.aqua}.
