# Filter Destination Tool

The **Filter Destination Tool**{.aqua} is a multi-use tool which will allow you to **set the destination**{.green} of a **filtered item type**{.aqua}.

You can assign it an inventory by **right clicking it**{.gold} **on the face of the block the**{.blue} **Pipe**{.aqua} **connects to**{.gold}. It will not work if you do not select the correct face of the inventory.
