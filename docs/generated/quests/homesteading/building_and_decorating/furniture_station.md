# Furniture Station

> Ideas above your station

The mod **Fantasy's Furniture**{.blue} adds beautiful and intricate furniture for you to decorate with.



The crafting system is a little different from usual, however. Each recipe costs only 1 each of **Clay, Cobbled Stone, and Planks**{.aqua}, and must be created in a **Furniture Station**{.aqua} **, which can be**{.aqua} **crafted in a Smithing Table**{.green} **using a**{.green} **Crafting Table**{.aqua} and **Leather**{.aqua}.
