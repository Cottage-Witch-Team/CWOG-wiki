# Niche Hooks for Niche Jobs

Different **Hooks**{.aqua} give different effects. Some are pure upgrades, but these will **grant other effects**{.green} ! **Heavy Hook**{.aqua} : Has a shorter cast range than other hooks. **Redstone Hook**{.aqua} : Gives you longer to reel in a fish, helpful if you have difficulty reacting quickly. **Note Hook**{.aqua} : Plays a note when a fish is approaching. Useful if you're not paying full attention, or have particles disabled. **Light Hook**{.aqua} : Allows you to cast farther.
