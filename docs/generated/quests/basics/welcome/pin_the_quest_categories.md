# Pin the Quest Categories

You might be wondering where all the quests are, when your screen looks like this:



![questmenu.png](/assets/textures/quest_images/questmenu.png)



See that **arrow on the left bar**{.green} ? **Hovering over that**{.gold} will show you all the categories.



![questmenu2.png](/assets/textures/quest_images/questmenu2.png)



Be sure to **click the Pin in the upper right**{.gold} to keep this sidebar open permanently!
