# Build a Trident

This modpack brings some changes to **Tridents**{.aqua}. Firstly, they may now **be crafted**{.green}, using **Trident Fragments**{.aqua}, which drop from **Elder Guardians**{.yellow}.



Once thrown, a trident with **Loyalty**{.aqua} will **return to the slot from which it departed**{.green}.
