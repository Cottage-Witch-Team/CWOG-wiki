# Developing Negatives

> A positive development

In order to **print your photographs**{.green}, you must first **develop the film**{.green}.



This is done by crafting **Thick**{.aqua}, **Awkward**{.aqua}, and **Mundane Potions**{.aqua} together with the **Color Film**{.aqua}. For **Black and White Film**{.aqua}, you only need a **Bottle of Water**{.aqua}.



Simply **combine them**{.gold} in a **Crafting Grid**{.aqua}.
