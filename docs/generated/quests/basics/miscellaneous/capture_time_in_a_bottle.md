# Capture Time in a Bottle

Did you know that you can **speed up the tick speed of a block**{.green} ? This can be used on things like **Compost**{.aqua} to make them progress faster.



Craft the **Time in a Bottle**{.aqua} and hold it in your inventory to accumulate time. Then, you can **shift right click**{.gold} on certain blocks to apply that time to them.
