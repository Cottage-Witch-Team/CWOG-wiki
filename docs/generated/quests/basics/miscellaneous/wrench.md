# Wrench

The **Wrench**{.aqua} is an item which can **rotate blocks**{.green}. Just **right click the block**{.gold} with the **Wrench**{.aqua}, and it will adjust the position based on where you click it.

Does not work on objects which have the same texture on all sides (such as planks).
