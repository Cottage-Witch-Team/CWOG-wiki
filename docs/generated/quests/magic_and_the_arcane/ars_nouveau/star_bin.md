# Star Bin

The **Starbin**{.aqua} will allow your **Starbuncle**{.green} to **delete items it picks up**{.green}. Be sure to set a filter first!



You can set a filter by **preparing an Allow/Deny Scroll**{.gold} and **clicking your Starbuncle**{.gold} with it.
