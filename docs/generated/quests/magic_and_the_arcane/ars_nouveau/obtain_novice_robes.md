# Obtain Novice Robes

> Unlike witches, mages do wear pants.

Use your newly-acquired **Magebloom Fiber**{.aqua} to craft yourself a set of **Novice Robes**{.aqua}, which will **increase the amount of mana**{.green} you have access to.
