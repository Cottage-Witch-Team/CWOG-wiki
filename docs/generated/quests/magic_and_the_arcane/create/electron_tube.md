# Electron Tube

The **Electron Tube**{.aqua} is a source of magical intelligence, allowing machines to **perform actions like players**{.green}, for example: The **Deployer**{.aqua} is capable of using many tools: shears, buckets, swords, and more. **Electron Tubes**{.aqua} also provide the basis for most of **Create's**{.blue} sorting mechanisms, or anything else which requires **intelligent function**{.green}.
