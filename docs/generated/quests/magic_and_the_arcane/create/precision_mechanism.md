# Precision Mechanism

The **Precision Mechanism**{.aqua} is crafted by setting up a **Mechanical Belt**{.aqua} and **three Deployers**{.aqua}.

You can view the recipe in **JEI**{.blue} by selecting the second tab at the top, **"Recipe Sequence"**{.pink}.

![precisionmechanism.png](/assets/textures/precisionmechanism.png)

The first Deployer should hold a **Cogwheel**{.aqua}, the second a **Large Cogwheel**{.aqua}, and the third a **Iron Nugget**{.aqua}. Each mechanism must **go through the process 5 times**{.gold}. There is only an **80% change of receiving**{.pink} the final product.
