# Andesite Casing

**Andesite Casing**{.aqua} is one of three different tiers of Casing, used to craft various machinery. It is crafted by applying **Andesite Alloy**{.aqua} to a **Stripped Log**{.aqua}. You can do this **manually by placing the**{.gold} **Stripped Log**{.aqua} in world and **right clicking it with the**{.gold} **Andesite Alloy**{.aqua}. It can also be automated by using a **Deployer**{.aqua}.
