# Getting the Shaft

**Shafts**{.aqua} can be used to convey **rotational force**{.green}, and **Cogs**{.aqua} both **convey and manipulate**{.gold} that force. Many machines have cogs in-built, which require an external **Cog**{.aqua} to power them. Others can connect to either a **Shaft**{.aqua} or the side of a **Cog**{.aqua}.
