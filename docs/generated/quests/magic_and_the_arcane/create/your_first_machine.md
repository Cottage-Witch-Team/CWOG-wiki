# Your First Machine

One of the first machines you'll want to build is the **Mechanical Press**{.aqua}. This, well, presses items down to create things like **Brass and Iron Sheets**{.aqua}, which you'll need for future projects.

To begin with, make a **Hand Crank**{.aqua} to power it. Going forward, you'll **automate your power**{.green}, but in a pinch, some elbow grease does the trick just as well.

Take this **Iron**{.aqua} and place it underneath the **Mechanical Press**{.aqua}.
