# Liquid to Solid via Compaction

Now that you have your **Melted Chocolate**{.aqua}, you'll want to **compact it into Bars using a**{.gold} **Mechanical Press**{.aqua}.

Place a **Basin**{.aqua} beneath a **Mechanical Press**{.aqua} and either **pump or bucket**{.green} the Chocolate into the Basin.

With enough power, the **Press**{.aqua} will automatically turn the liquid into **Chocolate Bars**{.aqua}, which can be retrieved by **right clicking with an empty hand**{.gold}.
