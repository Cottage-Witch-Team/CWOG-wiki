# Obtain a Dipper

> Is a "big dipper" joke too obvious?

The **Dipper**{.aqua} is used for making candles. It can be placed above a **Mixing Cauldron**{.aqua} **filled with**{.aqua} **Tallow**{.aqua} (rendered Animal Fat) and hung with String in order to **create Candles**{.gold}.



Unlike basic Candles, these can be placed together with Candles of different colors, and may be lit separately! **Tallow**{.aqua} is created in the Mixing Cauldron with **Animal Fat and Honeycombs**{.aqua}.
